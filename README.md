# 💰 สมุดบันทึกรายรับ-รายจ่าย (Personal Expense Tracker PWA)

แอปพลิเคชันบันทึกรายรับ-รายจ่ายส่วนตัว ใช้งานได้ทั้งบน **Web Browser, iPhone และ iPad** พร้อมระบบซิงค์ข้อมูลผ่าน Supabase (หรือใช้งาน Offline ในเครื่อง 100%)

---

## 📱 วิธีเปิดใช้งานบน iPhone / iPad

1. **ผ่าน Wi-Fi ในบ้าน (รันจากเครื่องคอมพิวเตอร์)**:
   - ตรวจสอบว่า iPhone/iPad และคอมพิวเตอร์ต่อ Wi-Fi วงเดียวกัน
   - เปิด Safari บนมือถือ แล้วพิมพ์ที่อยู่ IP ของคอมพิวเตอร์:
     ```
     http://192.168.1.44:3000
     ```
   - กดปุ่ม **แชร์ (Share)** ที่แถบล่างของ Safari (ไอคอนสี่เหลี่ยมลูกศรชี้ขึ้น)
   - เลือก **"เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)"**
   - จะได้ไอคอนแอปบนหน้าจอมือถือ สามารถกดเปิดใช้งานเต็มจอเสมือนแอปจริง

2. **เปิดใช้งานได้ทุกที่ทั่วโลก (ฟรี 100% ผ่าน Vercel)**:
   - นำโปรเจกต์นี้อัปโหลดขึ้น GitHub ของคุณ
   - ไปที่ [vercel.com](https://vercel.com) แล้วกด Import โปรเจกต์
   - จะได้โดเมน HTTPS ส่วนตัว (เช่น `https://my-expense.vercel.app`)
   - เปิด Safari บน iPhone/iPad แล้วกด "Add to Home Screen" ได้เลย ใช้งานได้ตลอดเวลาแม้ไม่ได้อยู่บ้าน

---

## ⚡ การเริ่มรันโปรแกรมบนเครื่อง (Local Development)

```bash
# รันโปรเจกต์ (เปิดให้เครื่องในวงแลนเข้าได้)
npm run dev

# คอมไพล์และทดสอบ Build
npm run build
```

---

## ☁️ การเชื่อมต่อ Supabase (Cloud Sync)

1. สมัครใช้งานฟรีที่ [supabase.com](https://supabase.com) แล้วกดสร้าง New Project
2. ไปที่เมนู **SQL Editor** ใน Supabase นำโค้ดจากไฟล์ `supabase-schema.sql` ไปวางแล้วกด **Run**
3. ไปที่เมนู **Project Settings > API** แล้วคัดลอก:
   - `Project URL`
   - `anon public key`
4. เปิดเว็บแอปของเรา กดไอคอนรูปเฟือง ⚙️ (ตั้งค่า) แล้ววางค่าทั้งสองลงไป กด **"บันทึก & ทดสอบเชื่อมต่อ"**
5. ข้อมูลทั้งหมดจะซิงค์ขึ้น Supabase แบบอัตโนมัติ ทุกเครื่องจะเห็นข้อมูลตรงกันทันที!
